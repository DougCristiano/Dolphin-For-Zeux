# Dolphin for ZeuX — mirror não-oficial

Este repositório redistribui um build **oficial e sem modificações** do
[Dolphin Emulator](https://dolphin-emu.org/), usado como fonte de instalação
automática (1-click) pelo [ZeuX](https://github.com/DougCristiano/ZeuX).

**Este repositório não é afiliado, endossado ou mantido pelo projeto Dolphin.**
"Dolphin" é um nome do projeto original — este mirror existe apenas para
contornar a ausência de releases estáveis via GitHub API no projeto oficial.
